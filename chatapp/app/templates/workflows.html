How Workflows Work

Workflows let you run agent prompts on a schedule and track results over time. Each run invokes the Data Explorer Agent, which queries your connected manufacturing systems and returns a prioritized report.

Creating a Workflow

  • From the chat, ask a question and click "Save as Workflow" on the response
  • Or click the + button in the sidebar
  • Choose a model and set a schedule (hourly, daily, or weekdays)

Schedule Options

  • Manual: run on demand only
  • Every X hours: runs at a fixed interval (1–24h)
  • Daily: runs once per day at a specified UTC time
  • Weekdays: runs Monday through Friday at a specified UTC time

Priority Classification

Each result is automatically classified as urgent, normal, or low by the agent based on the response content. Urgent results indicate safety issues, failures, or out-of-spec conditions.
